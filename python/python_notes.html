01. Print Function

Display text, variables, and formatted output.

Common ways to use print()

Syntax Purpose
print("Suresh VJ") Print a string.
print(x) Print a variable value.
print(x, y) Print multiple values with a separator (space by default).
print("Python", end="@") Use end to change the ending character and keep the next print on the same line.
print("09","12","2016", sep="-") Use sep to separate printed values.
print(f"Hello {x}") Format a value using an f-string.
"Hello {}".format(x) Format a string using str.format().

year = 2026

print("Hello", name)
print("Python", end="@")
print("Learning")

02. Variables & Constants

Store values and give them meaningful names.

Variable declaration

x = 10
name = "Suresh VJ"

# Multiple assignment
x, y = 26, "Suresh VJ"

# Same value assigned to both names
a = b = "Python"

Naming rules

  • Names cannot start with a digit.
  • Do not use spaces in variable names.
  • Names can start with a letter or underscore.
  • Use meaningful names such as total_price.
  • Python names are case-sensitive.

Constants by convention

Python does not enforce constants, but uppercase names communicate that a value should not be reassigned. Constants are often kept in a separate module and imported where needed.

# constants.py
PI = 3.14
GRAVITY = 9.8

# main.py
import constants
print(constants.PI)
print(constants.GRAVITY)

03. Data Types

Understand the built-in types used to represent values.

Numeric

int, float, complex
Examples: 26, 10.5, 2+3j

String

str
Example: "Python"

Sequence

list, tuple, range

Mapping

dict
Example: {"name": "Sam"}

Set

set
Example: {1, 2, 3}

Boolean & None

Remember: Python values are objects. Use type(value) to inspect a value's type and isinstance(value, SomeType) to test a type relationship.

Number literal examples

decimal_num = 100
binary_num = 0b110101
octal_num = 0o215

print(type(decimal_num))
print(binary_num, octal_num, hex_num)

Python uses prefixes 0b for binary, 0o for octal, and 0x for hexadecimal literals.

04. Operators

Perform calculations, comparisons, assignments, and membership tests.

Arithmetic

+ - * / // % **

a, b = 10, 3
print(a + b)   # 13
print(a / b)   # division
print(a // b)  # floor division
print(a % b)   # remainder
print(a ** b)  # power

Comparison

== != < > <= >=

age = 21
print(age >= 18)  # True
print(age == 21)  # True
print(age != 10)  # True

Assignment

= += -= *= /= //= %= **=

count = 5
count += 2
count *= 3
print(count)  # 21

Logical, identity & membership

and, or, not; is, is not; in, not in

print(5 > 2 and 8 > 3)
print("py" in "python")
x = None
print(x is None)
Use == to compare values and is to check object identity. Python's equality operator is ==; === is not a Python operator.

05. Type Casting

Convert values using built-in constructors when conversion is supported.

Common conversion constructors

Numeric

int(), float(), complex()

Text & Boolean

str(), bool()

Collections

list(), tuple(), set(), dict()

value = "42"

06. Mutable & Immutable

Whether an object can be changed after it is created.

🟢 Mutable objects

The object can be modified in place.

  • list
  • dict
  • set
items = [1, 2]
items.append(3)
print(items)  # [1, 2, 3]

🔵 Immutable objects

The object itself cannot be modified in place.

  • int, float, bool
  • str, tuple
  • NoneType
text = "Py"
text = text + "thon"
print(text)  # a new string value

07. Object Interning

Python may reuse certain immutable objects to optimize memory and speed.

Key idea

Object interning/caching means Python may let multiple references point to the same object for selected values. The exact behavior can depend on the Python implementation and runtime context, so do not rely on it for correctness.

a = 10
b = a
print(a == b)  # True: equal values
print(a is b)  # True here: same referenced object

# For value comparison, normally use ==
Best practice: use == to compare values. Use is for identity checks, commonly value is None.

08. Strings & String Methods

Strings are ordered, sliceable, and immutable sequences of characters.

Declaration, indexing & slicing

s1 = 'Python'
s2 = "Learning"
s3 = """Multi-line
string"""

word = "Python"
print(word[0])    # P
print(word[-1])   # n
print(word[1:4])  # yth

Forward indexing starts at 0; negative indexing starts at -1 from the end. Slice end positions are excluded.

Frequently used string methods

Method What it does
capitalize() Uppercases the first character and lowercases the rest.
title() Title-cases words.
casefold(), lower(), upper() Change letter casing.
swapcase() Switches uppercase and lowercase characters.
istitle(), islower(), isupper() Check casing patterns.
center(width, fillchar) Returns a centered string.
strip(), lstrip(), rstrip() Remove leading/trailing whitespace or specified characters.
count(sub) Counts occurrences of a substring.
find(sub), rfind(sub) Find first/rightmost occurrence; return -1 if absent.
startswith(prefix), endswith(suffix) Check the beginning or ending of a string.
index(sub), rindex(sub) Find a substring; raise ValueError if absent.
isnumeric(), isdecimal(), isdigit() Check different categories of numeric characters.
isalnum(), isalpha(), isspace() Check alphanumeric, alphabetic, or whitespace content. 
text = "  Python Learning  "
print(text.strip())

10. Tuples

Ordered, immutable collections that allow duplicate values.

Declaration & methods

empty = ()
single_item = (4,)  # comma makes it a tuple
values = (1, 2, 2, 3)
also_tuple = 1, 2, 3

print(values[0])
print(values.count(2))
print(values.index(3))
  • Tuples are ordered and support indexing and slicing.
  • Tuples can contain values of different types.
  • Use a trailing comma for a single-item tuple: (4,).
  • Available common methods include count() and index().

11. Sets

Mutable collections of unique, hashable elements with no positional indexing.

Declaration & methods

empty_set = set()  # {} creates an empty dictionary
values = {1, 2, 2, 3}
values.add(4)
values.discard(2)
print(values)
Method Purpose
add(value) Add an element.
clear() Remove all elements.
copy() Return a shallow copy.
difference(other) Elements in the first set but not the other.
difference_update(other) Update the set to keep only its difference.
discard(value) Remove an element if present without raising an error if absent.
intersection(other) Elements common to both sets.
intersection_update(other) Keep only common elements in the set. 
a = {1, 2, 3, 4}
b = {3, 4, 5}

print(a.difference(b))      # {1, 2}
print(a.intersection(b))    # {3, 4}
Set elements must be hashable. Lists, dictionaries, and sets cannot be elements of another set.

12. Slicing

Access a subpart of a sequence with start, end, and step.

Syntax: sequence[start : end : step]

x = [10, 20, 30, 40, 50, 60]

print(x[2:5])    # [30, 40, 50]
print(x[2:5:2])  # [30, 50]
print(x[-2:])   # [50, 60]
print(x[:3])    # [10, 20, 30]
print(x[::-1])  # reversed copy
Slice Meaning
x[2:5] Start at index 2, stop before index 5.
x[:5] Start at the beginning, stop before index 5.
x[2:] Start at index 2 and continue to the end.
x[-2:] Take the final two elements.
x[::-1] Traverse the sequence in reverse.
The end index is excluded. Slicing works on sequences such as strings, lists, and tuples; sets and dictionaries do not support slicing.

13. Concatenation

Join compatible sequences using + or augmented assignment.

first = "Suresh"
last = " VJ"
print(first + last)  # Suresh VJ

a = [1, 2]
b = [3, 4]
print(a + b)         # [1, 2, 3, 4]

x = (10, 20)
y = (30,)
print(x + y)         # (10, 20, 30)

first += "!"
print(first)

String concatenation joins strings, list concatenation joins lists, and tuple concatenation joins tuples. The operands need to be compatible types.

14. Sort & Reverse

Arrange values or produce a reversed sequence.

Sorting

numbers = [4, 1, 7, 2]
print(sorted(numbers))                 # ascending
print(sorted(numbers, reverse=True))   # descending

numbers.sort()  # sorts list in place

sorted() returns a new sorted list. list.sort() changes the list in place.

Reversing

items = [1, 2, 3]
print(items[::-1])        # reversed copy
print(list(reversed(items)))

items.reverse()           # in-place

Use slicing or reversed() for a reversed iteration/copy. Sets and dictionaries do not support sequence slicing.

For strings, sorted("python") returns a list of characters. Use "".join(sorted("python")) to combine them into a string.

15. Comprehensions

Create lists, sets, dictionaries, and generator expressions concisely.

List comprehension patterns

x = range(0, 11)

# Without a condition
result = [i + 2 for i in x]

# With an if condition
filtered = [i + 2 for i in x if i <= 5]

# With if/else expression
mapped = [i + 2 if i > 3 else i for i in x]

print(result)
print(filtered)
print(mapped)

Set comprehension

unique_squares = {n * n for n in range(6)}
print(unique_squares)

Dictionary comprehension

x = range(5)
lookup = {f"key{i}": i + 2 for i in x}
print(lookup)

Tuple creation

A generator expression uses parentheses and produces values lazily. To build a tuple, wrap it with tuple().

values = tuple(n * 2 for n in range(5))
print(values)

When to use

  • Transform each item.
  • Filter items using a condition.
  • Build a dictionary from key-value pairs.
  • Keep comprehensions readable; use loops for complex logic.
